# 제보 데이터와 운영진 검토

Node.js 24에서 이 디렉터리의 `npm ci`와 `npm test`를 실행한다. PGlite에 테스트용 auth·storage 테이블과 역할을 구성해 마이그레이션의 재실행, 익명·회원·운영진 권한, 중복 제보, 부분 승인, 상충 정보와 실패 후 재시도를 검사한다.

Supabase 개발 프로젝트에서는 `setup.sql`을 사용한다. 앱은 Google 로그인과 비공개 evidence 버킷을 사용한다. 운영진 권한은 신뢰된 관리자만 app_metadata.role에 admin을 지정해 부여한다. 개발 프로젝트와 운영 프로젝트의 데이터·키를 분리한다. 로컬 검사는 외부 프로젝트에 접속하지 않는다.
