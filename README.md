# 잇:다 (eat 多)

서울대학교에서 식이 제한이 있는 구성원이 학내 비학식당의 메뉴별 식재료 정보를 확인할 수 있도록 돕는 반응형 웹앱입니다.

## 처음 작업을 맡으면

개발 경험이 없어도 [첫 작업 안내](docs/first-task.md)를 순서대로 따라 하면 됩니다. AI에서 이 저장소 폴더를 열고, 맡은 일을 평소 말로 알려 주세요.

> 저장소의 첫 작업 안내와 팀 규칙을 읽고 함께 진행해 줘. 내가 맡은 일은 [작업 내용]이야. 작업 범위와 완료 기준을 먼저 보여 주고, 구현·검증·PR 작성까지 도와줘.

AI가 [팀 작업 지침](AGENTS.md)에 따라 관련 문서와 완료 기준을 찾아 확인합니다. 팀원은 완성된 화면과 PR의 확인 결과를 직접 검토하고, PR은 성은영(`@Eun-Y0ung`)의 승인 후 병합합니다.

## 개발 환경

기획상 프론트엔드는 React와 JavaScript, 지도는 NAVER Maps API, 백엔드는 Supabase, 배포는 Vercel을 사용합니다. 현재 브랜치에는 앱 코드가 없습니다. 개발 환경이 정해지면 실제 설치·실행 명령, 필요한 환경변수 이름, 화면 확인 방법을 여기에 추가합니다.
