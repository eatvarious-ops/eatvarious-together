# 잇:다 (eat 多)

식이 제한이 있는 서울대학교 구성원이 학내 비학식당의 메뉴별 식재료 정보를 확인할 수 있도록 돕는 웹앱

## 처음 작업을 맡으면

AI에서 이 저장소 폴더를 열고, 맡은 일을 다음과 같이 지시합니다.

> 저장소 파일 읽고 팀 규칙에 맞게 작업해 줘. 내가 맡은 일은 [작업 내용]이야.

AI가 [팀 작업 지침](AGENTS.md)에 따라 관련 문서와 완료 기준을 찾아 확인합니다. 작업 결과를 검토하고, PR은 성은영(`@Eun-Y0ung`)의 승인 후 병합합니다.

## 개발 환경

기획상 프론트엔드는 React와 JavaScript, 지도는 NAVER Maps API, 백엔드는 Supabase, 배포는 Vercel을 사용합니다. 현재 브랜치에는 앱 코드가 없습니다. 개발 환경이 정해지면 실제 설치·실행 명령과 필요한 환경변수 이름을 추가합니다.
