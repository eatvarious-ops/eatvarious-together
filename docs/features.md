## 마이페이지

| ID | 기능명 | 우선순위 |
| --- | --- | --- |
| MY-01 | 회원가입 | Must |
| MY-02 | 로그인 | Must |
| MY-03 | 로그아웃 | Must |
| MY-04 | 내 정보 등록 | Won't |
| MY-05 | 내 정보 조회 | Won't |
| MY-06 | 찜 식당 등록 | Won't |
| MY-07 | 찜 식당 조회 | Won't |
| MY-08 | 내 제보 목록 조회 | Must |
| MY-09 | 내 기여 현황 조회 | Could |

Must는 필수, Should는 우선 고려, Could는 여유 시 고려, Won't는 이번 MVP 제외다. Should·Could는 자동으로 이번 작업에 포함하지 않는다. 기능 하나를 구현할 때도 백엔드·프론트엔드 작업과 검증 범위를 구분한다.
