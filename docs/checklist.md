# 검증 기준

각 항목은 같은 번호의 [작업](tasks.md)을 검토할 때 다시 사용하는 기준이다. 확인 결과는 PR 본문에 번호·확인 방법·관찰한 결과 순서로 남긴다.

- [ ] 1. README에서 프로젝트 참고 자료와 팀 문서, 첫 작업 안내, 병합 승인자를 찾을 수 있다. 첫 작업 안내를 따라 작업 선택부터 결과 확인과 PR 제출까지 진행할 수 있다. AI 작업 지침에 범위 확인, 기존 변경 보존, 실제 검증, 미확인 항목 보고, 승인 전 병합 금지가 적혀 있다. PR 양식에서 작업 번호와 검증 결과를 기록할 수 있다.
