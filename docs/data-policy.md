# 식재료·필터·제보 정책

## 확정 사항

- 메뉴마다 고기, 돼지고기, 계란, 우유, 견과류를 각각 기록한다. 각 항목의 상태는 포함·미포함·미확인 중 하나다. 자료가 없으면 미확인으로 둔다.
- 식이 제한 조건을 충족하는 메뉴가 하나 이상인 학내 비학식당을 필터 결과에 표시한다. 지도와 목록에 같은 판정 결과를 사용한다.
- 제보는 특정 식당의 특정 메뉴에 연결한다. 접수만으로 공개 정보를 변경하지 않는다. 확인 후 반영된 정보로 메뉴 상세와 식당 필터 결과를 갱신한다.

## 판정 예시

학내 비학식당에서 메뉴 A만 선택 조건을 충족해도 해당 식당은 지도와 목록에 표시한다. 메뉴 A에 변경 제보가 들어오면 확인 전에는 기존 결과를 유지한다. 확인·반영 후 조건을 충족하는 메뉴가 0개가 되면 그 조건의 검색 결과에서 식당을 제외한다.

## 구현 전에 정할 사항

- 조건별 충족 근거와 미확인 항목이 섞인 메뉴의 처리 기준. 돼지고기 미포함만으로 할랄 여부를 확정하지 않는다.
- 제보 확인 담당자, 인정할 근거, 기존 정보와 제보가 상충할 때의 처리 절차.
