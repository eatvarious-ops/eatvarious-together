# 작업 목록

실제로 진행하는 작업을 한 줄씩 등록한다. 기능 개발 작업은 확정된 기능정의와 사용자 요청을 근거로 AI가 범위와 완료 기준을 정리해 등록한다. 정책이나 범위가 미정이면 해당 결정만 팀에 확인한다. 작업 하나는 PR 하나에 대응한다. 추가 설명이 필요하면 AI가 [작업 카드 양식](task-card-template.md)으로 정리하며, 팀원에게 직접 작성을 요구하지 않는다.

등록 형식: 작업 번호 · 작업명 · 담당자 · 완료 기준 · 상태

담당자는 확인된 팀원만 적고 모르면 미배정으로 둔다. 상태는 예정 → 진행 중 → 검토 중 → 완료로 관리한다. 미해결 결정·필수 검사 실패로 진행할 수 없으면 보류와 사유를 적는다. PR 제출이나 인계 준비는 검토 중이며, 승인·병합과 완료 기준 충족을 확인한 뒤 완료로 바꾼다.

- 1 · 팀 하네스 구성 · 담당 미배정 · 한 문장 시작, 영역별 개발 경계, 검증·PR·인계 규칙이 연결되고 검증 기준 1을 충족한다 · 검토 중
- 2 · 최신 PRD·기능정의서와 저장소 문서 동기화 · 담당 미배정 · 기능 ID·우선순위와 범위·정책을 최신 원문에 맞추고 미확정 경계를 명시한다 · 검토 중
