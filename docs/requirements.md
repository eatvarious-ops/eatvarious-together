# MVP 요구사항

기준: [최신 PRD](https://docs.google.com/document/d/1mKtalKrWTfE0ME1OB4wfT6ntDxUADFulkBatFlnQEnU/edit) 및 [기능정의서 v1.1.0](https://docs.google.com/spreadsheets/d/1gz_mPcyv0wkcNCSgEGfBRO6cN5kmBx0osrvvxVq84Rk/edit), 2026-11-20 확인. 상세 기능과 우선순위는 [기능 색인](features.md), 판정·제보 규칙은 [데이터 정책](data-policy.md)을 따른다. 문서는 요구사항 요약이며 구현 완료를 뜻하지 않는다. 작업 전 Drive 원문을 다시 확인하고 충돌은 임의로 해석하지 않는다.

## 대상과 서비스

식이 제한이 있는 서울대학교 구성원이 학내 비학식당과 메뉴별 식재료 정보를 확인하는 React·JavaScript 기반 반응형 웹앱이다. 모바일과 PC를 지원하고 한국어·영어 화면을 제공한다. 지도는 NAVER Maps API, 데이터·Google OAuth·사진 저장은 Supabase, 배포는 Vercel을 사용한다.

## 제공 범위

- 식당·메뉴의 한글명과 영문명 검색, 지도·목록 탐색, 식당 상세와 전체 메뉴 목록 제공
- 메뉴별 돼지고기·소고기·닭고기·기타 고기·해산물·계란·유제품의 포함·미포함·미확인 상태와 항목별 마지막 확인일·확인 방법 제공
- 돼지고기 없음·소고기 없음·고기 없음·해산물 없음·계란 없음·유제품 없음 6개 필터 제공
- 기존 정보 수정, 새 메뉴·식당 등록, 폐점·판매 종료 제보와 운영진 검토·공개 반영
- 비로그인 조회, 구글 로그인 후 제보·신고, 마이페이지의 내 제보 목록과 반려 사유 확인
- 운영진 전용 관리자 페이지에서 대기 목록 조회, 현재 공개 정보와 비교, 승인·반려

로그인과 내 제보 목록은 최신 PRD·시트에서 MVP에 포함됐다. 개인 식이 정보와 찜 기능은 제외한다. Should·Could 항목의 우선순위는 Must와 구분하며 이번 작업 범위에 없는 기능을 함께 구현하지 않는다.

## 제외 범위

학내 학식당, 캠퍼스 밖 식당(서울대입구역 일대 포함), 견과류 등 알레르기 유발 성분 정보, AI 식재료 추론, 메뉴명 자동 번역, 개인 식이 정보·찜 저장은 MVP에서 제외한다. 메뉴 영문명은 운영진 등록 또는 사용자 제보로 수집한다. 네이티브 앱과 별도 PostgreSQL 이관은 웹앱 운영 이후 검토한다.

## 성과 지표

PRD 기준 배포 4주 내 주간 재방문율 40%, 사용자 제보로 정보가 추가·수정된 메뉴 수가 초기 메뉴 수의 50% 이상, UT 설문 만족 이상 응답률 60% 이상을 목표로 한다. 측정 도구 구현은 별도 작업 범위를 정한다.
